# 教育研究投稿指南

手机与电脑适配的静态网站，可部署到 GitHub Pages。无依赖，无需构建。

## 部署
1. 建议新建公开仓库 `education-journal-guide`。
2. 解压发布包，将 index.html、sw.js、manifest.webmanifest、icon.svg、.nojekyll 上传到仓库根目录，不能只上传 ZIP。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. Branch 选择 main，目录选择 / (root)，点击 Save。
5. 等待部署完成，从 Pages 页面打开实际网址。

若仓库属于 sueivan，项目网址为 https://sueivan.github.io/education-journal-guide/ 。实际地址以 GitHub Pages 页面显示为准。

## 手机使用
安卓浏览器菜单选择添加到主屏幕；iPhone Safari分享菜单选择添加到主屏幕。
首次联网加载并完成缓存后，可离线查询。期刊外链仍需联网。
主屏幕方式不是APK。安装入口与缓存能力依浏览器而异。

## 功能与数据
17本候选期刊；中文投稿难度筛选与个人评价；研究方向、收录线索、出版路线、OA与费用；收藏、比较、笔记导入导出。
投稿难度默认待评估，由用户填写个人判断，不是录用概率。
收录标签待逐刊实时复核；部分费用待核实；不展示未经核实的IF与分区。
数据整理日期：2026-10-15。不会自动同步出版社更新。
收藏与评价保存在当前浏览器，通过导出笔记备份；不跨设备自动同步。

## 单机版本
Journal_Guide_Offline.html 可在支持本地HTML和JavaScript的浏览器离线打开。
